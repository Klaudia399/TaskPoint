TASKPOINT — BETA 0.5 — logowanie Firebase
=======================================

ZMIANY W TEJ WERSJI
- Logowanie e-mail/hasło przez Firebase Authentication.
- Loguje się użytkownik dodany wcześniej w Firebase Authentication > Users.
- Wylogowanie oraz przypomnienie hasła (przez e-mail).
- Dane demonstracyjne lokalne, rozdzielane według Firebase User UID na urządzeniu.
- Dotychczasowe widoki: budowy, materiały, zamówienia, akceptacje, transport,
  magazyn, dokumenty i komentarze są zachowane.

BARDZO WAŻNE — OGRANICZENIA
- Rejestracja/logowanie NIE nadaje pracownikowi uprawnień do dokumentów firmy.
- Przełącznik ról jest nadal symulatorem (nie zabezpieczeniem).
- Zamówienia, WZ i raporty NIE SYNCHRONIZUJĄ SIĘ między urządzeniami.
- Cloud Firestore nadal ma pozostać z zasadą `allow read, write: if false;`.
- Nie dodawaj rzeczywistych poufnych danych ani pracowników do aplikacji,
  dopóki nie wdrożymy bezpiecznych reguł dostępu i współdzielonych danych.
- KOD aplikacji w publicznym GitHub Pages jest publiczny. Firebase Web Config
  jest publiczną konfiguracją, a nie hasłem administratora. Nie wrzucaj
  kluczy konta serwisowego ani innych sekretów do repozytorium.
- Firebase Authentication pozwala na usługę logowania; konfiguracja nie
  blokuje technicznie samodzielnego założenia konta przez API. Zapis do
  Firestore pozostaje zablokowany — nie ustawiaj reguł auth != null dla wszystkich.

INSTRUKCJA AKTUALIZACJI NA GITHUBIE (MACBOOK)
1. Rozpakuj TaskPoint-BETA-0.5.zip w Finderze.
2. Na GitHub: https://github.com/Klaudia399/TaskPoint otwórz Add file > Upload files.
3. Wybierz WSZYSTKIE pliki z rozpakowanej paczki (nie wgrywaj ZIP).
4. Potwierdź zapis przyciskiem Commit changes.
5. Sprawdź opublikowaną stronę: https://klaudia399.github.io/TaskPoint/
6. Wpisz e-mail i hasło konta w Firebase Authentication > Users.
7. Jeśli ekran jest stary, odśwież stronę; w Chrome możesz też usunąć dane
   witryny dla klaudia399.github.io, ale stracisz lokalne dane demonstracyjne.

JEŚLI LOGOWANIE MA PROBLEM Z DOMENĄ
- Firebase Console > Authentication > Settings > Authorized domains.
- Dodaj domenę `klaudia399.github.io` bez https:// i bez /TaskPoint/.

NIE EDYTUJ FIRESTORE RULES W TYM KROKU.
Następny etap: konta z potwierdzonymi rolami, bezpieczne uprawnienia Firestore,
a następnie wspólne zamówienia, zmiany i transport.
