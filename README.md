# TaskPoint BETA 0.7

Prototyp aplikacji PWA z realnym logowaniem Firebase Authentication i synchronizacją testowych danych przez Cloud Firestore. Instrukcja dla MacBooka: `INSTRUKCJA-START.txt`.

**UWAGA:** nie wprowadzać poufnych danych ani plików firmowych w wersji beta. Reguły w `FIRESTORE-RULES-0.7.txt` należy opublikować w Firebase przed aktualizacją strony. Obecne wersje nie obsługują plików WZ i powiadomień push; nie wdrożono też pełnej kontroli spójności i automatycznych kopii zapasowych.
